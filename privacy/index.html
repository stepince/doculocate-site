Privacy details

Last updated September 27, 2026.

This marketing site

The interactive demonstration uses prepared passages from one fictional document. It does not upload files, send search queries to an API, or run a live semantic search. This site includes no analytics scripts, advertising trackers, or browser storage. The hosting service may process standard request information, such as IP addresses and access logs.

Document processing in the application

The current application uploads your document to its server. An uploaded file, its extracted text, and search data are held in server memory. Removing a document, capacity-based eviction, or a server restart clears it from the application’s document store. This describes application storage, not infrastructure logs, backups, or any external provider’s retention.

Search and optional AI providers

Semantic retrieval runs on the application server using a local embedding model. If an external AI provider is configured for reranking, the application sends your query and candidate passages to that provider. The provider’s data handling and retention policies apply. We do not make a blanket promise that external providers never retain data or use it for training.

Deployment matters

The current implementation uses a shared server document store and does not yet provide separate user accounts or private workspaces. Access controls and hosting configuration must be considered before uploading sensitive documents. These details describe the current implementation; they are not a security certification or a guarantee about every deployment.

Your choices

You can explore the examples on this website without uploading any documents. Before using an application deployment, review its configuration and provider policies. Use its document removal control to remove documents from the running application store.
