Privacy details

Last updated October 2, 2026.

This marketing site

The interactive demo uses fictional files and prepared results. It does not upload documents, run live searches, contact AI providers, or store your files. This site contains no analytics or advertising scripts. While a page is open and visible, it sends a short request to the application’s health endpoint about once a minute so the application is ready when you click through. The request carries no document or search data, but the application host can see it, including your IP address and standard request details. Hosting services may process standard request information such as IP addresses and access logs.

The active document on the application server

The application uploads and processes one active document at a time. Original file bytes, extracted text, viewer data, and the search index are held in server memory. Replacing the active document, using Reset, or restarting the server clears the current document from that store. This is not a promise about infrastructure logs, backups, browser history, or provider retention.

Recent-file history in your browser

The app uses browser local storage to keep up to five recent upload entries. For files up to 3 MiB, it attempts to save the file contents so selecting a history entry can upload and restore the file. Larger files can appear in history without cached contents and need uploading again. Browser storage limits can reduce the history retained.

Browser history can survive a page reload and a server restart. Reset removes the server’s active document but does not erase this browser history. Clear history removes the saved history entries and their cached contents; it does not remove the active document from the server. To clear both, use Reset and Clear history. Your original files on disk are unchanged.

Search and optional AI processing

Base search runs on the application server using semantic and keyword retrieval. If an AI provider is configured, the application sends your query and candidate passages to it for result reranking and possible answer generation. Provider retention and training policies apply. No blanket promise is made that providers do not retain data or use it for training.

Access to the instance

The current application has a single shared active document and does not implement user accounts or isolated workspaces. Anyone with access to that instance may be able to search, retrieve, replace, or remove its active document. Deployment access controls matter, especially for sensitive files.

Your choices

You can explore this marketing demo without uploading anything. Before uploading to an application instance, understand its network access and provider configuration. Review browser history on shared computers, and use the separate Reset and Clear history controls when you want to remove both server and browser copies.
