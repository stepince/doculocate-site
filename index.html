CLEAR ABOUT YOUR DATA

Your documents should
remain your documents.

Understand where processing happens before you upload. Here’s how the current application works.

Held in server memory

Uploaded files and extracted text are kept in the running server’s memory. Removing a document or restarting the server clears it from this store.

Semantic search runs on the server

The search model processes document text on the application server. This is not browser-only processing.

Optional external AI processing

When AI reranking is configured, your query and candidate passages are sent to that provider. Provider data policies apply.
